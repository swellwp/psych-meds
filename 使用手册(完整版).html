精神药物服药单 APP · 使用手册

把纸质精神科服药单搬进手机：按「日期 × 早 / 中 / 晚 × 药物」记录，支持停药标色、血药浓度、机构/科室与住院/门诊管理。

一句话上手： 用手机浏览器打开下方链接 → 新建自己的账号 → 新建病人 → 在「服药单」里点 ＋ 药物 添加药品 → 点格子填剂量即可。
应用链接： https://swellwp.github.io/psych-meds/（固定域名，永不变）

一、如何打开并"装到桌面"

本应用是一个网页（无需下载安装），数据保存在你自己的手机浏览器里。

iPhone（Safari）

打开链接后，点底部工具栏的 分享 图标（方框带向上箭头）。
下滑找到并点 添加到主屏幕 → 命名（如"服药单"）→ 添加。以后像 APP 一样从桌面打开。

安卓（Chrome / 系统浏览器）

打开链接，点右上角 ⋮ 菜单。
点 安装应用 或 添加到主屏幕 → 确认。
⚠️ 微信里打开的局限：微信内置浏览器无法真正固定到桌面，且与系统浏览器是两套互不连通的存储。建议在系统浏览器中打开并添加到桌面；若已在微信里录入数据，换系统浏览器后请先用"数据 → 生成同步二维码 / 导入数据"把数据迁过去（见第七节）。

二、账号：多人共用、数据互不混淆

首次打开会进入"账号选择页"。每个医生/使用者建立自己的账号，各账号的病人数据完全隔离、互不可见。

新建账号：点 ＋ 新建账号 → 填姓名（如"张医生"）→ 可选设 4 位 PIN 密码（保护病历隐私）→ 创建并进入。
切换账号：首页右上角"账号名 ▾"可切换；或"数据"菜单 → 切换账号。
账号管理："数据"菜单 → 账号管理 → 可改名、设/改密码、删除账号。
同一台科室平板，也能多人各用各的账号，互不干扰。带 PIN 的账号进入时需输密码。

三、病人管理（机构 / 科室 / 住院·门诊）

新建病人

首页点右下角 ＋ 浮动按钮 → 打开"新建病人"表单。
填姓名、病案号（稳定标识，一般不变）。
机构 / 科室：下拉选择；列表里没有就选 ＋ 新建/其他… 直接输入（如"嘉誉护理院 · 精神科门诊"）。新建科室时可选 住院 或 门诊 类型。
管理类型：选 住院 或 门诊。住院病人需填床位号、入院日期、状态（在院/出院/死亡）；门诊病人无需床位，按随访管理。
诊断：从常用精神科诊断中多选（也可留空）。
点保存 → 病人出现在首页（按机构/科室分组）。
床位可随入院记录变更：同一病人不同时间可能住不同床、或换床/出院/死亡。点病人 → 编辑 → 在"入院记录"里增删记录（每次记录含床位号、入院日期、状态、出院日期）。同一床位不同时间住不同病人也正确——系统按"日期落在哪段入院区间"判定当天床位。

编辑 / 删除

  • 点病人进入详情 → 顶部 编辑 可改基本信息、入院记录、诊断。
  • 在病人详情页底部点 删除该病人 可移除（谨慎操作，删除后不可恢复）。

换床 / 转科（保留完整住院轨迹）

住院病人同科室换床、或转到其他科室时，不用重新建病人——系统保留一条完整的"住院轨迹"，可随时按日期回溯历史床位。

在病人详情页点 🛏 换床 / 转科 按钮（门诊病人无此按钮）。
弹出的面板有三个标签：
  • 换床：填新床位号与日期。系统会关闭当前在院记录，并追加一条带"换床"标记的新的在院记录，原床位与轨迹都保留。
  • 转科：选择目标科室与日期。病人改挂到新科室，并追加一条带"转科"标记的在院记录；管理类型（住院/门诊）随之同步。
  • 出院 / 死亡 / 转院：选终末状态与日期；可勾选"同时隐藏该病人"（见下）。
病人详情页的 住院轨迹 会列出每一次入院 / 换床 / 转科 / 出院，并标注类型与所属科室。卡片上的"入院 N 次"只统计真正的入院，换床 / 转科不计入；如发生过换床或转科，会额外提示"换床 / 转科 N 次"。

出院 / 死亡后隐藏，但数据保留

病人出院或死亡、暂时不再住院时，可把记录从首页隐藏；病历数据完整保留，随时可恢复。

方式一（出院时）：在 出院 / 死亡 / 转院 面板勾选"同时隐藏该病人"，保存后即隐藏。
方式二（随时）：病人详情页点 🙈 隐藏记录；已隐藏的病人点页面顶部的 恢复显示 横幅即可恢复。
首页底部会出现一个默认收起的 已隐藏病人 分组，展开可查看或恢复；搜索时隐藏病人仍能被搜到（标记"已隐藏"并排在结果后面）。

首页排序规则

  • 科室顺序：住院科室会按名称里的数字自动排序（如"一病区、二病区、三病区"依次排列，带数字的科室排在无数字的"心理门诊"等之前），无需手动调整。
  • 住院病人：在科室内按床位号自然顺序排列（如 3062 排在 3100 之前，是数值序而非字符串序），科室头标注"按床位"。
  • 门诊病人：按疾病大类归集（如焦虑障碍、抑郁障碍、双相及相关障碍等 DSM-5 大类），同一大类内按姓名拼音顺序排列；科室头标注"按病种"。

四、服药单：填药、填剂量、停药标色

添加药物（含剂型 + 规格）

进入病人 → 切到 服药单 标签 → 点 ＋ 药物。
在搜索框输入或按分类（抗精神病药 / 抗抑郁药 / 心境稳定剂 / 镇静催眠抗焦虑 / 抗痴呆药 / 多动症药 / 物质依赖 / 其他常用药）选择药名。
按诊断智能推荐：打开"添加药物"时，顶部会按该病人的诊断类别和你既往的录入历史推荐常用药（如精神分裂症常用抗精神病药、双相常用心境稳定剂等）。点推荐项即可直接进入配置；无诊断时则回退到全局最常用药物。已在该病人服药单里的药不会重复推荐。
弹出的表单里填：剂型（片剂/针剂/胶囊…）、规格（如 1mg / 25mg / 200mg）、用药频率、服用方式（口服/肌注…）。
点 添加到服药单。
💡 同一通用名可不同剂型/规格并存：例如"利培酮 1mg 片剂 口服"和"利培酮 25mg 针剂 肌注"是两列；"喹硫平 25mg"与"喹硫平 200mg"可同时出现在单上。系统只在通用名+剂型+规格完全相同时才提示"已在服药单中"。
库里没有的药：在"添加药物"页底部的 自定义 输入框输入药名 → 点 添加，会自动加入你的药品库并进入服药单（见第六节）。

列标题怎么看

每列第一行是药名；第二行紧凑显示：规格 剂型 频率 服药时机 方式。例如：

喹硫平
200mg 片剂 tid 餐后 口服

填剂量 / 停药

点某个"早/中/晚"格子 → 弹出快捷剂量（该药常用剂量 chips）或自己输入。
点 停药 这一格会标红底，其后空格显示浅红底，直到你重新填入剂量，表示"停药及停用期间"。
红底＝停药 浅红＝停用期间
"同前（复制上日剂量）"：某格点开后选 同前（复制上日剂量），会自动把上一日同时间段该药的实际剂量填进来（不再显示容易误认为"停药"的"/"）；若之前没有记录则留空。剂量不变或要沿用前一日时，直接选它即可，不必重复输入。

停药药物可隐藏（展示更简洁）

某药停药后，若想在服药单上把它藏起来、只保留数据，可在该药列标题（点药名）→ 设置面板里点 隐藏该药（停药后更简洁）。隐藏后该药从服药单网格与打印中消失，但所有剂量记录与血药浓度仍完整保留。

隐藏：点药名 → 设置面板 → 隐藏该药（停药后更简洁）。
恢复：服药单底部会出现一个 已隐藏药物 区域，点其中的药名 → 显示 即可恢复。

打印服药单

在 服药单 标签右上角点 打印。
生成清晰的可打印服药单（含病人信息、日期轴、药物列、血药浓度说明）。用浏览器/系统"打印"功能可另存为 PDF 或直接打印，交予护士站或归档。

五、血药浓度（TDM）

进入病人 → 切到 血药浓度 标签 → 点 添加血药浓度。
选药品、填抽血日期、数值与单位（ng/mL、μg/mL、mmol/L 等）→ 保存。
也可在"服药单"里点某药列标题 → 记录血药浓度 快速录入。
记录可修改：每条血药浓度右侧有 ✎ 编辑 按钮，点开即预填原值，改完保存即可（不必删除重填）；✕ 为删除。

保存后，服药单网格会出现一行"血"，自动按内置参考范围判读并标色：

红＝偏高 蓝＝偏低 绿＝正常

内置参考范围的药物：锂盐、丙戊酸钠/镁、卡马西平、奥卡西平、拉莫三嗪、氯氮平、奥氮平、喹硫平、利培酮、帕利哌酮、阿立哌唑、氟哌啶醇、阿米替林、氯米帕明、多塞平等（添加药物时会提示"建议定期监测血药浓度"及参考区间）。

六、药品库维护（自定义药名）

  • 内置药品库已收录约 127 种常用精神科药物（8 大类），不可修改、不可删，保证底库稳定。
  • 新增自定义药名：在"添加药物"页输入库里没有的药名 → 添加，会自动归入"我的药品"分类并持久保存，下次直接可选。
  • 管理药品库："数据"菜单 → 管理药品库 → 列出你自定义的药名，可逐个删除（注意：删除仅从药品库列表移除，已录入服药单中的该药不受影响）。

七、拍照识别录入（服药单 / 心理测评）

把纸质单子拍照，由你自己的大模型 API 自动识别并录入，省去手抄。

先配置识别设置：数据管理 → 识别设置，选服务商（OpenAI / 通义千问 / 腾讯混元 / 自定义兼容接口），填入 Base URL、模型名、API Key（仅存本机当前账号），保存。
识别服药单：进入病人 → 服药单 → 点 📷 识别 → 拍照或选图 → 等待识别 → 在「核对」页确认药物（可移除误识项）→ 确认导入。系统按「通用名＋剂型＋规格」去重，并写入对应日期的早/中/晚剂量。
识别心理测评单：进入病人 → 测评 → ＋ 新增测评 → 选量表 → 📷 拍照/上传识别 → 自动保存为一条测评记录（可在测评列表核对或删除）。
已内置 25 种常用量表，按功能分组、带标准判读（仅供参考，以临床判断为准）：
· 认知功能：MMSE、MoCA
· 抑郁/焦虑：HAMD、HAMA、SDS、SAS、PHQ-9、GAD-7
· 精神症状/睡眠：PANSS、PSQI、YMRS（杨氏躁狂）
· 双相情感障碍：MDQ（情绪障碍问卷·双相筛查）、BSDS（双相谱系诊断量表）、HCL-32（轻躁狂症状清单）、BDRS（双相抑郁评定量表）、FAST（功能评估简表）、CGI-BP（临床总体印象-双相改良版）
· 强迫及相关障碍：Y-BOCS（耶鲁-布朗强迫量表，10 项，总分 0-40，含「强迫思维 / 强迫行为」两维度）
· 其他常用：ADL、CDR、NPI、SCL-90、EPQ、MMPI、16PF
SCL-90 填写说明：「总分」填 量表总分（90 个条目之和，0-450）；「总均分」= 总分÷90，填总分后会自动算出，也可手填。任一篇因子分≥2 提示该因子阳性。
测评填错不用删重填：在测评列表点开某条记录 → 右下角 编辑 即可修改日期 / 总分 / 维度分 / 总均分，保存后覆盖原记录（不会新增重复条目）。
⚠️ 识别用的照片只在本次识别时发送一次到你所填的模型接口，不进入本应用的数据库、也不经本应用服务器；API Key 仅存本机。识别结果建议核对后再使用。

八、数据同步与备份

数据默认只存在本设备浏览器。跨设备 / 跨浏览器想复用，有三种方式（都只在设备间直传，不经服务器，保护病历隐私）：

① 二维码同步（最方便）

在原设备"数据"菜单 → 生成同步二维码 → 用手机相机扫码，会自动打开带同步参数的链接并导入。
若扫码未自动跳转，复制链接/文本，在目标设备"数据"菜单 → 粘贴同步码导入 粘贴即可。
⚠️ 同步是整盘覆盖当前账号。目标设备已有数据时，请先确认哪边是最新，避免覆盖；数据量大时二维码容量有限，系统会提示改用下方"导出/导入"文件方式。

② 导出 / 导入文件（最稳妥，推荐定期备份）

备份："数据"菜单 → 导出全部数据（JSON 备份） → 保存/转发这个 .json 文件。
恢复："数据"菜单 → 导入数据（从备份恢复） → 选中备份文件 → 覆盖当前账号。

③ 示例数据

"数据"菜单 → 载入示例病人 可体验（含住院与门诊示例）。

九、常见问题（FAQ）

问题处理
换了手机/浏览器，原来的数据看不到了？数据按"浏览器"隔离。在原设备用"生成同步二维码"或"导出全部数据"，再到新设备"粘贴同步码导入 / 导入数据"。
同名的药怎么出现两列？只有"通用名+剂型+规格"完全相同时才会去重；不同剂型/规格（如 1mg 片 vs 25mg 针）本来就该并存，属正常。
血药浓度数值没变色？该药可能无内置参考范围，或数值/单位填写不完整。可手动核对参考区间。
病人删错了能找回吗？不能。请定期"导出全部数据"备份，误删可从备份恢复。
自定义药名想删？"数据 → 管理药品库"删除（不影响已录入的服药单）。
多人共用一台平板怎么不混？各自建账号；首页"账号名 ▾"切换，数据天然隔离。

十、隐私与数据安全提示

  • 所有病历数据仅保存在使用者自己的浏览器本地，不上传任何服务器（二维码同步也是设备间直传，不经过云端）。
  • 清除浏览器缓存/卸载浏览器会丢失数据，请定期"导出全部数据"备份。
  • 多人共用设备请使用独立账号，并为敏感账号设置 PIN 密码。
  • 本工具为临床工作辅助记录，不替代医嘱与正式病历，用药调整请遵临床规范。
